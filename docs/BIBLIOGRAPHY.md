# HORMATHOS active bibliographic register — design HEXIS 3.1, V3-001, V3-002

Transposition of §18 of the deposited contract. The previous register is preserved in the [historical roadmap](../archive/docs/history/v2.1/03_ROADMAP_OPERATIVA_IT.md), in the archive.

These are the sources used directly, to be taken into the project register in V0 while keeping the historical one. Citation obligations concerning Latin, transfer and retired estimators no longer bind 3.1 if they have no function in the text. No source outside the register is introduced implicitly into the proposal.
